# 얼굴 알아맞히기 게임 — 20칸으로 배우는 CNN

AI 연구실 해설 · CNN 특집 · 비전공자용

**바로 보기:** 1편 https://adminmrobo.github.io/cnn_face_game_lab/ · 2편 https://adminmrobo.github.io/cnn_face_game_lab/part2.html

가림막 뒤에 하루, 시아, 모아 중 한 사람이 서 있습니다. 박사, 초파리 연구원, 주판봇이 이어달리기로 얼굴을 맞힙니다. 게임판 20칸을 한 칸씩 가면 이미지 인식 AI인 CNN(합성곱 신경망)의 공식 열 개가 모두 풀립니다. 코드와 수식을 몰라도 버튼만 눌러 따라갈 수 있습니다.

## 구성

| 구간 | 칸 | 내용 |
|---|---|---|
| 얼굴은 숫자판 | 1~2 | 8×8 도트 얼굴, 통째 비교가 깨지는 이유 |
| 박사의 돋보기 | 3~8 | 합성곱, 필터, 출력 크기, 패딩, 스트라이드, ReLU |
| 초파리의 요약 | 9~12 | 최대·평균 풀링, 밀림에 견디기, 채널 |
| 전달 요원의 줄 서기 | 13~14 | 펼치기, 완전연결층 |
| 주판봇의 확률 | 15~17 | 소프트맥스, 교차 엔트로피 손실, 경사 하강 |
| 한 판 돌리기 | 18~20 | 파라미터 수, 전체 흐름, 한계 |

그 밖에 「CNN은 어디에 쓰나」(분류·탐지·분할·전이 학습), 대결(가운데 얼굴만 배우고 한 칸 밀린 얼굴 맞히기), 도감(LeNet-5·AlexNet·VGG·ResNet), 지식 색인, 온톨로지·서지 꾸러미가 있습니다.

## 2편 — 얼굴 찾기 게임 (21~26칸)

| 구간 | 칸 | 내용 |
|---|---|---|
| 찾기 | 21~24 | 창 하나로 묻기, 창 밀기, 겹친 비율(IoU)과 겹친 상자 정리(NMS), 맞힘·놓침·헛짚음 |
| 칠하기 | 25 | 종류별 칠하기와 하나하나 칠하기 (의미 분할 · 개체 분할) |
| 빌려 쓰기 | 26 | 1편의 돋보기를 가져와 새 식구 후보 배우기 (전이 학습 · 특징 추출) |

대결은 "창을 한 칸씩 밀까, 세 칸씩 건너뛸까"입니다.

## 읽을 때 알아 둘 점

- 도트 얼굴, 돋보기 숫자, 정확도·확률은 모두 페이지 안에서 계산한 **설명용 모형**의 값입니다. 실제 얼굴 데이터가 아닙니다.
- 대결의 승패는 "가운데 얼굴만 보고 배웠을 때"의 결과입니다. 조건을 바꾼 결과도 대결 아래에 적었습니다.
- 1편의 고양이·강아지·거리 그림과 거리 색칠판은 AI로 만든 이미지입니다(실제 사진 아님). 페이지에 내장했고 `img/`에 사본이 있습니다.
- 표지와 구간 머리의 게임 화면은 코드로 그린 것입니다(액자 모니터 + 캐릭터 표정). 같은 콘셉트의 픽셀아트 그림 지시문은 `docs/SCENES_game_screens.md`에 있습니다. 로봇은 주판봇만 씁니다.
